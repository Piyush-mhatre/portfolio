AI Financial Advisor

A conversational financial advisor powered by Gemini, with real multi-turn memory — it remembers what you've already asked in the conversation. Part of the Explainable AI Financial Advisor project — this is the live backend, not a mockup.

$ ./advisor --chat

    AI-generated, educational guidance — not professional financial advice. Your conversations are stored only in this browser (localStorage), never on the server — up to 25 chats, and clearing your browser data removes them. There's a daily message limit per visitor, shared across all your chats, to keep the free API quota available for everyone.

    Part of the Explainable AI Financial Advisor project · Backend hosted on Render, frontend on Vercel
